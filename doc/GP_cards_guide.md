# 纸牌会客厅

纸牌会客厅是支持 **1–8 人**的 Tabletop 风格联机 3D 纸牌沙盒。玩家围坐在正八角桌旁，自行约定规则、摆牌、合堆、洗牌和发牌。开局使用一副背面朝上的标准扑克。房主可通过「扑克」切换到 54 张标准扑克（52 张常规牌和大小王），通过「UNO」切换到经典 108 张牌组。切换会替换桌面与全部手牌。「清空」清除当前牌局，「结束本局」进入原版协议的未排名结算。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动散牌、短拖抽取牌堆顶牌 | 左键拖拽 |
| 移动整叠牌堆 | 按住左键约 0.28 秒后拖拽，或按住 `Shift` 拖拽 |
| 合堆 | 将散牌或牌堆拖到另一张牌或另一叠牌上松手 |
| 收入、重排或打出手牌 | 拖到屏幕底部松手。在手牌区左右拖拽重排，向上拖出后可落桌或合堆 |
| 打开卡牌或牌堆菜单 | 右键短点。牌堆菜单可抽 1 张或给所有在桌玩家各发 1、5、7 张 |
| 翻面、旋转、洗牌 | `F` 翻面，`Q / E` 旋转 15°（`Shift` 为 45°），悬停牌堆按 `R` 洗牌 |
| 从牌堆摸牌 | 悬停牌堆按 `1–9`，摸对应张数到自己手牌 |
| 放大看牌 | 悬停可见正面或自己的手牌时按住 `Alt` |
| 镜头 | 右键拖拽环绕，中键拖拽或 `WASD` 平移，滚轮缩放，`Space` 复位，`V` 切换俯视 |

`Esc` 打开框架共享菜单，`Tab` 查看玩家及延迟，`F3` 查看总排名。开发时可在编辑器打开 `game.tscn` 按 F6，以一个本地操作者预览八席牌桌。

## 联机隐私

房主保存完整牌序与全部手牌，并按接收者生成开局快照和每次操作的增量。客机只收到自己的手牌牌面、公开散牌的牌面及公开牌堆的顶牌牌面。其他席位只收到手牌张数，桌边牌背动画从这份公开信息生成。牌翻回背面或移入他人手牌后，本机立即清除对应的可见牌面和放大预览。房主作为权威端可读取完整牌局，曾经公开的信息也可能被玩家记住。

## 接入规则脚本

继承 `CardTableRuleHook`，在开局前为房主的游戏实例赋值 `game.rule_hook_factory = MyRule.new`。工厂每局返回一个新实例，默认工厂创建 `SandboxRuleHook`。用 `setup()` 获取房主牌局，用 `validate_action()` 拒绝动作，用 `on_state_event()` 跟踪已提交的变化。达成胜负条件时，从 `evaluate_settlement()` 返回 `should_finish = true` 和符合原版协议的结果，填齐全员身份、状态与名次。游戏负责校验和发布结果、等待各端挂载结算页，并由房主提交。接口与事件细节见[架构文档](GP_cards_architecture.md)。
